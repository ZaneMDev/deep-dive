# 🌊 DeepDive

A modern full-stack, ocean-themed discussion platform inspired by Reddit built as a monorepo using React (Vite) and Node.js (Express).

> ⚠️ **Development Status:** This project is an active work-in-progress. Both the frontend user interface and backend architectural systems are currently still being worked on, so things are subject to change.

---

## 🛠️ Tech Stack

- **Frontend:** React + TypeScript + TailwindCSS v4
- **Backend:** Node.js + Express + TypeScript (`tsx` watcher)

---

## 🚀 Local Setup & Installation

Follow these quick steps to get the project on to your local machine.

### 1. Clone the Project

```bash
git clone https://github.com/ZaneMDev/deep-dive.git
cd deep-dive
```

### 2. Run Backend

1. Go to the backend folder and install packages:
    ```bash
    cd backend && npm install
    ```
2. Start the server (listening on port 5000):
    ```bash
    npm run dev
    ```

### 3. Run Frontend

1. Open a new terminal window, go to the frontend folder, and install packages:
    ```bash
    cd frontend && npm install
    ```
2. Start the Vite development server (listening on port 5173):
    ```bash
    npm run dev
    ```
